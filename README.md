# Lathebe Skills Development

A responsive website sharing youth training programs, organizational information, and contact options. It includes a programs listing, gallery, contact form, newsletter signup, light/dark theme, and responsive navigation.

## Run locally

Open `index.html` in a browser, or serve the repository root with a local static web server. The forms use Netlify Forms and require deployment to Netlify to submit successfully.

## Deploy

The site is configured for Netlify in `netlify.toml`. Connect the repository to Netlify and use the repository root as the publish directory; no build command is required.
